# UT Rental Atlas

**给 UT Austin 社区的一张中文租房地图。**

从 West Campus 到 UT Shuttle 沿线，把分散在物业官网、管理公司和租房平台的信息放在一起，帮助准备来奥斯汀的学生、研究人员和教职工了解街区、比较房源。

### [打开租房地图 ↗](https://lsj-i.github.io/ut-austin-rental-atlas/)

你可以在地图上选择区域，按户型、预算、入住日期、家具和校车片区筛选，再通过汇总表格、楼盘归类或并排对比整理候选房源。需要进一步研究时，也可以导出 CSV / JSON；每条记录保留原始来源和核查时间。

网站将支持自动获取的公开来源每 **6 小时**更新一次，并保留各来源的成功、失败状态；尚未接入的来源继续明确标注为人工核查。区域地图使用 APD 近90天公开报案数据，帮助理解不同区域的相对报案密度。

这是一份持续完善的租房索引：**不是全市场清单，也不是物业后台的实时库存**。报价、费用、资格和入住日期仍以物业确认为准；区域颜色不是官方治安评级或安全承诺。

发现错误、过期房源或值得加入的来源，欢迎通过 [Issues](https://github.com/LSJ-i/ut-austin-rental-atlas/issues) 提供链接。项目独立维护，与 UT Austin、APD 及各物业无隶属关系。
